\section*{The problem}
A regional carrier must route a fleet of vehicles from a depot to serve
several thousand delivery addresses daily, subject to vehicle capacities and
delivery time windows. The instance is far too large to solve exactly: the
project is to produce good routes, and to \emph{prove} how good they are.

\section*{Learning goals}
Model a vehicle routing problem at scale; design and tune construction and
improvement heuristics (nearest neighbor, savings, 2-opt, simulated
annealing from Chapter~16); compute lower bounds via LP relaxation and
Lagrangian relaxation; formulate the set-covering master problem and
experience column generation on a restricted instance; communicate results
with gap reporting.

\section*{Stages}
\begin{enumerate}
  \item \textbf{Data.} Generate or download a large instance (several
    thousand stops; e.g.\ open address data plus a distance API or random
    geometry). Clean and structure it.
  \item \textbf{Baseline.} Construction heuristic + local search. Report
    tour costs and runtimes as instance size grows.
  \item \textbf{Bounds.} LP relaxation on subsamples; Lagrangian relaxation
    of the capacity constraints; compare bounds to heuristic solutions.
  \item \textbf{Column generation.} Set-covering master over routes;
    pricing as a shortest path with resource constraints on a reduced
    network.
  \item \textbf{Report.} Best routes, optimality gaps, scaling behavior,
    and a discussion of which techniques earned their complexity.
\end{enumerate}
