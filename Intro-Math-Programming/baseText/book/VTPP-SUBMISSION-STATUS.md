## Recommendation on the HTML question

Say **yes** to HTML. The EPUB pipeline (tex4ht) produces the HTML as an
intermediate — a web edition costs almost nothing extra, and the book
already has a live in-browser reader at
https://open-optimization.github.io/open-optimization-or-book/read/ plus
the interactive visualizations site. HTML is also the strongest format for
ADA accessibility (real MathML + alt text).

## Points worth raising with VTP&P

1. **Workflow:** the manuscript is LaTeX, not Word. The repo already
   produces reviewer-ready PDF and a validated EPUB3 (MathML math, alt
   text on all images, per-figure license credits). Offer them the built
   files; clarify whether their production step will regenerate from
   LaTeX or post-process our output.
2. **Equation alt text at this scale** (7,768 equations) is only feasible
   machine-generated. The spreadsheet uses ClearSpeak (the standard screen
   readers use); flag the "(literal reading)" rows for their accessibility
   reviewer and ask if this format meets their ADA interpretation before
   anyone hand-polishes thousands of rows.
3. **Numbering churn:** adding figure/table numbers everywhere shifted all
   existing numbers. Reviewer feedback should cite the NEW numbering
   (current build).
