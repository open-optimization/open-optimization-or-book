# External source: A First Course in Linear Algebra (Lyryx)

This directory contains source material from *A First Course in Linear
Algebra* by Ken Kuttler, adapted and distributed by Lyryx Learning,
used under the Creative Commons Attribution 4.0 International license
(see `LICENSE.txt`).

The book *Mathematical Programming and Operations Research* (this
repository) uses the Lyryx style files (`LyryxLinAlgStyle.sty`,
`LyryxMathStyle.sty`) and adapts selected linear algebra content from
this source. Attribution appears in the front matter of the book.
