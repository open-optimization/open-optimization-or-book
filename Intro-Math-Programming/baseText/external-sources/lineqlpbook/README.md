# External source: Linear Inequalities and Linear Programming (Cheung)

This directory contains content adapted from *Linear Inequalities and
Linear Programming* by Kevin Cheung (Carleton University), used under
the Creative Commons Attribution-ShareAlike 4.0 International license
(see `LICENSE`).

The book *Mathematical Programming and Operations Research* (this
repository) adapts LP theory material (basic feasible solutions,
duality, Farkas' lemma, complementary slackness) from this source.
Attribution appears in the front matter of the book.
