# Instructive code

This directory contains assorted Jupyter notebooks for instructors and
course developers — classroom exercises (TSP heuristics, simulated
annealing), algorithm comparisons, and scripts for generating
illustrations and animations used in the book. It is not primarily
intended for students studying the book.

**Note:** this code is not particularly well maintained at this point.
Notebooks may use outdated package versions or need minor fixes to run.
For current, maintained examples, see the code accompanying the book
chapters and the [interactive visualizations](https://open-optimization.github.io/open-optimization-or-book/visualizations/).
